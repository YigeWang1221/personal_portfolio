## 围绕求职过程组织工作区 {#overview}

JobApply 将岗位调研、申请材料、浏览器填表和后续跟进放在同一个工作区。我围绕求职者在不同申请中反复使用的信息，开发了 Java 后端和 React 界面。

我用 Project、Session 和 Job 组织这些信息：Project 保存求职方向与材料，Session 保存调研和讨论，Job 保存具体申请。对话可以继续展开，同一份申请的记录也可以独立保留。

## 工作区界面设计 {#workspace-design}

我将工作区按求职方向、调研对话和岗位申请组织。全局视图集中呈现投递阶段、面试安排与待跟进事项；申请总表按岗位保留记录，让用户从一次对话转到下一次对话时，仍能找到同一份申请。

## 调研与申请共用模型工具循环 {#agent-loop}

我实现了共用的 `AgentLoop`，驱动岗位调研与申请填写。每次调用模型前，循环先接收用户的新消息，再由当前任务组装上下文；模型返回工具调用后，循环执行工具、将结果加入对话，然后进入下一轮。

`SessionLoop` 提供调研上下文，以及搜索岗位、读取 JD、管理候选池和选择简历的工具。`HarnessLoop` 提供申请资料和浏览器工具，处理选定岗位的表单。Spring AI 负责模型消息与工具 Schema，Java 循环负责执行和持久化。

不同招聘页面的字段、导航和补充要求各不相同。我将早期的固定步骤流程改为模型驱动的循环，让模型根据页面和工具反馈选择下一步。模型通过 `ask_user` 请求补充信息，通过 `finish` 返回填写报告，用户在浏览器中审阅并提交。

## 上下文组装与对话续接 {#context}

我将稳定的工作说明与变化的任务信息分开。每次请求依次包含 Agent 指令、当前资料与计划、历史对话。调研侧接收求职方向，申请侧接收选定岗位、可复用事实和上传文件引用。

对话层保留工具调用与结果之间的 ID 关联。重建模型消息时，如果某次调用因中断缺少结果，对话层会补入中断说明。请求包含最新页面快照，之前的页面操作则作为记录保留，减少反复传入的整页内容。

任务运行期间，用户的新消息进入收件箱。循环在下一次模型调用前读取这些消息，让用户可以在申请过程中调整要求；用户补充回答后，Agent 从保存的对话继续执行。

## 用 Skills 和分层资料复用方法与经历 {#memory}

我通过 Skills 索引向模型提供方法名称和简介，由模型调用 `read_skill` 读取所需正文。招聘网站的操作经验与通用填表方法分别保存在文件中，不需要写进循环代码。

个人事实按照明确的优先级解析：本次回答、当前 Project 的覆盖内容、父 Project 的覆盖内容、基础资料。`unset` 可以屏蔽继承值。求职者因此可以复用教育与项目经历，同时为不同方向维护各自的材料。

记忆写入模块支持新增、替换和删除事实与经验。修改 Skill 时，模块定位唯一匹配的段落并替换。Markdown 保存便于阅读的资料，JSON 和 JSONL 保存申请运行记录与对话。

## 申请任务调度与实时界面 {#architecture}

我将任务执行与展示任务的页面分开。`ApplicationRunner` 通过 Worker 池调度申请，并分别设置总并发数与单站点并发数。当某个网站的名额被占用时，调度器可以先启动队列中另一个网站的任务。

后端通过 SSE 推送带序号的运行事件。React 按 Session 或 Job 订阅，更新对话、当前操作和申请视图。连接恢复后可以补发缓冲区中的事件；收到重置信号时，界面重新读取保存的视图。刷新界面与后台任务循环因此各自独立。

## 具体设计借鉴 {#references}

我参考其他 Agent 项目的具体机制，在 Java 运行时中实现了对应功能：

- **OpenMAIC：** 借鉴用户交接机制，用 `ask_user` 将控制交回用户，并接收下一条消息继续执行。[导演循环源码](https://github.com/THU-MAIC/OpenMAIC/blob/dff201b49857918885cc5ebadb4a8af254b6ae9d/lib/chat/pi/director-loop.ts)。
- **Deep Agents：** 借鉴中断后的工具调用处理，在对话层补齐缺失的工具响应。[工具调用补齐源码](https://github.com/langchain-ai/deepagents/blob/3e7d5faa9d275beb3d54f11266aac3c60e3d50b9/libs/deepagents/deepagents/middleware/patch_tool_calls.py)。
- **Hermes Agent：** 借鉴记忆更新操作，为持久化事实与经验提供 add、replace 和 remove 接口。[Memory 工具源码](https://github.com/NousResearch/hermes-agent/blob/e5dad4ac57ad11d39fe18b1ac895c0e0ae5b6494/tools/memory_tool.py)。
