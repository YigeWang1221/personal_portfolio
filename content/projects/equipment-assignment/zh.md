## 平台功能 {#platform}

这个平台为教师和学生支撑一门物联网课程的日常运转：

- **设备借用。** 学生申请实验设备，教师审批，归还后自动更新库存。
- **班级与分组。** 教师管理班级、小组和学生，支持 Excel 导入导出。
- **小组作业。** 教师布置作业，小组成员在富文本编辑器中共同编辑提交内容，再由教师批改。
- **导出与展示。** 作业可以导出为 PDF，优秀作品会汇集到公开的作品展示中。
- **媒体。** 图片、项目视频和压缩包存放在对象存储中，视频可以边播放边拖动。
- **权限。** 区分教师与学生角色，登录时需要验证码。

## 架构 {#architecture}

- **后端。** 基于 Java 17 的 Spring Boot 2.7，十一个控制器共提供 {{fact:endpoints}} 个 REST 接口；MyBatis-Plus 负责 MySQL 的数据映射；登录、学生和教师三类拦截器守护各个路由。
- **文档。** Apache POI 负责 Excel 导入导出；iText html2pdf 把作业从 HTML 渲染成 PDF。
- **媒体。** 文件存放在 MinIO 中，由专门的控制器提供访问。
- **前端。** Vue 3 + TypeScript + Element Plus，基于开源模板 vue-element-plus-admin 搭建，集成了富文本编辑器和视频播放器。

## 媒体：分片上传与可拖动的视频播放 {#media}

课程视频体积很大。上传时通过 MinIO SDK 并预先告知文件大小，大文件因此会以分片（multipart）方式上传。播放时经过一个实现了 HTTP Range 请求的接口（`Range`、`If-Range` 和 `206 Partial Content`），播放器可以直接跳到任意位置，而不必先下载整个文件。

## 小组作业协同编辑 {#editing}

我将小组成员关系用于作业访问控制：读取和保存前，后端先检查学生所属小组，再访问对应提交内容。应用通过读写锁串行处理保存操作，协调共享作业文档的更新。

## 作业锁与目录缓存 {#maintenance}

我用 `SET NX PX` 实现按作业划分的 Redis 锁，通过过期时间管理锁的生命周期，并用 Lua 比较后删除的操作释放锁。锁的归属对应具体作业，不再由整个应用共用。

我还为设备目录和作品展示实现 Redis 缓存。写入路径清除受影响的缓存条目，Redis 不可用时，读取回退到 MySQL。

## 教学文档与材料管理 {#next}

教师通过应用管理班级与小组。Apache POI 处理表格导入和导出，iText html2pdf 将作业内容转换为 PDF。MinIO 保存图片、视频和归档文件，将课程管理与教学材料连接起来。
